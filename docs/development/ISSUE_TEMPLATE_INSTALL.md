# Issue intake

Engineering Task collects WHAT, WHY, Acceptance Criteria (DONE), Boundary, and optional References. Human defines the request once; one Codex or Claude Code Builder executes engineering autonomously under GOVERNANCE.md. No risk levels or repeated Human approval fields.

Choose Learning Record in GitHub New Issue to enter the subject, learning objectives and sources (PENDING is accepted). Add V2/V3 milestones, quality evidence, final integration and archive links later through Issue comments.

Learning records and unapproved V2/V3 semantics remain owned by ChatGPT + Human. Engineering agents must mark missing semantic approval PENDING/BLOCKED; a learning record is not automatically an engineering job.

The form alone starts no AI. See AUTONOMOUS_OPERATIONS.md and INSTALL.md for existing App/gh sign-in, on-demand startup, native GitHub protections, deployment setup and actual verification status. Do not confuse CI or closure with learning mastery.
