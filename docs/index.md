## How We Learn｜我們如何學習

CLH 以**學習為先（Learning-First）**：先讀原始教材、深度學習與驗證，再發布成可追溯的網站內容。工程只是支撐學習的手段，不是學科本身。

[![Copy Learning Hub 教材製作與發布流程：Phase A 學習與教材製作、Phase B 本機來源管理、Phase C 工程發布、Phase D 學習回饋與結案，另含角色責任矩陣與兩種 Issue 生命週期](development/Copy%20Learning%20Hub%20Workflow%20Infographic.png){ loading=lazy }](development/Copy%20Learning%20Hub%20Workflow%20Infographic.png){ target=_blank }

*點擊圖片可開啟完整大圖（手機可雙指縮放）。*

- **Phase A 學習與教材製作**：提供原始 PDF、建立 Learning Record、製作 V2／V3 教材並核准。
- **Phase B 本機來源管理**：原始與產出檔案存放於本機 RAW_DATA。
- **Phase C 工程發布**：建立 Engineering Task，經 Plan、實作、CI、Protected Merge 後發布至 Pages。
- **Phase D 學習回饋與結案**：回填學習紀錄、持續修訂，完成後結案。
